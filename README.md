# Najiba Final

## Project Description
Najiba Final – Project source code and development repository.

## Getting Started

### Prerequisites
- Node.js
- pnpm

### Installation

Clone the repository:

```bash
git clone https://github.com/belhajmabroukyasmine-cmyk/najiba_final.git
```

Go to the project directory:

```bash
cd najiba_final
```

Install dependencies:

```bash
pnpm install
```

Start the development server (if the `dev` script is configured):

```bash
pnpm dev
```

## Git Workflow

After modifying the code, use the following commands to upload your changes:

```bash
git add .
git commit -m "Update project"
git push
```

### Git Commands Explained

- `git add .` – Stage modified and new files.
- `git commit -m "Update project"` – Save changes in a commit.
- `git push` – Upload commits to GitHub.
